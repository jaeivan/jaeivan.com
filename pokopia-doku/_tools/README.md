## Updating the Pokémon data

`pokopia-doku/data.js` is generated by `build-data.mjs`. Don't edit it by hand.

When a DLC, event or patch adds Pokémon:

1. If the update has its own dex (e.g. an event dex), add it to `DEX_PAGES` in
   `build-data.mjs`. New Pokémon in an existing dex need no changes.
2. From the repo root, run the builder (Node 18+, about 10 minutes):

   ```bash
   node pokopia-doku/_tools/build-data.mjs
   ```

   Add `--keep-cache` to resume after a failure without re-downloading.

3. Check the report:
   - Per-dex counts: confirm the new Pokémon showed up.
   - `X: missing ...`: gaps in the source data. Some are real (Magikarp, Lugia and Ho-Oh have a "???"
     specialty; Ditto has no favorites or flavor). Fix wrong ones in `OVERRIDES`.
4. If needed, use `MERGE` for alternate forms that count as one Pokémon (e.g.
   Tatsugiri) and `EXCLUDE` for story characters you can't befriend (e.g. Kyogre).
5. Play a couple of Unlimited grids locally, then commit `data.js`.

Changing `data.js` changes which grid each date generates, so today's daily puzzle
may change for anyone mid-game when it deploys.

## Adding a themed day

Themes live in `pokopia-doku/themes.js` (instructions at the top of the file). On a
themed day, one header is the theme, e.g. "J's favorite Pokémon".

- **One date:** add to `dated`, e.g.
  `{ date: "2026-11-02", name: "J's favorite Pokémon", pokemon: ["eevee", "umbreon", ...] }`
- **Weekly:** add to `weekly` with `weekday` (0 = Sunday … 6 = Saturday).
- **Random:** add to `pool`. About 25% (`poolChance`) of normal days pick a pool
  theme, with no repeats within 7 days.

Pick Pokémon by id from `data.js` or with `match: (p) => ...`, and aim for 8 or more.
Preview a day locally with `?date=2026-11-02` (the live site ignores it). Unknown ids,
and themes that can't make a valid grid, log a console warning; the latter fall back
to a normal grid.

Editing `pool` or any theme can change the grids of past and future days.

## Tuning difficulty

All in `pokopia-doku/script.js`:

- `DIFFICULTIES`: per difficulty, the category-rating mix, answers per square,
  guesses (`null` = unlimited) and hint rules.
- `WEEKDAY_DIFFICULTY`: which difficulty each weekday's Daily uses.
- `GROUP_RATINGS` / `RATING_OVERRIDES`: how hard each category is (1 easy to 3 hard).
  Categories with fewer than 12 Pokémon get +1 automatically.
