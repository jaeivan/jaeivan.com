## Updating the Pokémon data

The game reads everything from `pokopia-doku/data.js`, which is generated by
`build-data.mjs` from [Serebii's Pokopia dex](https://serebii.net/pokemonpokopia/)
(specialties and their descriptions, habitats, favorites, flavors) and
[PokeAPI](https://pokeapi.co/) (generation, evolution, legendary status).
Don't edit `data.js` by hand.

### When a DLC, event, or patch adds Pokémon

1. **New dex page?** DLCs and events get their own dex page on Serebii
   (see "Pokédex (Basin)", "Pokédex (Event)" in Serebii's Pokopia sidebar).
   Add the new page to `DEX_PAGES` at the top of `build-data.mjs`.
   Pokémon added to an existing page need no changes.
2. **Run the builder** from the repo root (Node 18+, takes ~10 minutes):

   ```bash
   node pokopia-doku/_tools/build-data.mjs
   ```

   If it dies partway (network hiccup), resume without re-downloading:

   ```bash
   node pokopia-doku/_tools/build-data.mjs --keep-cache
   ```

3. **Read the report** it prints:
   - `<dex> dex rows: N` / per-dex entry counts — check the new Pokémon showed up.
   - `X: missing ...` — blanks on Serebii. Some are real (Magikarp, Lugia and
     Ho-Oh have a "???" specialty; Ditto has no favorites or flavor). Fix wrong ones with
     `OVERRIDES` in `build-data.mjs`.
   - `specialty descriptions: N/N` — a new specialty's description comes from its
     Serebii specialty page automatically.
4. **Handle oddities** in `build-data.mjs` if needed:
   - `MERGE` — alternate-form pages that should count as one Pokémon
     (e.g. Tatsugiri's three forms).
   - `EXCLUDE` — story characters you can't befriend (e.g. Kyogre).
5. Open `/pokopia-doku/`, play a couple of Unlimited grids, then commit `data.js`.

Changing `data.js` changes which grid each date generates, so today's daily
puzzle may change for anyone mid-game when you deploy.

## Adding a themed day

Themes live in `pokopia-doku/themes.js` (instructions are at the top of that file).
On a themed day, one header is the theme, e.g. "J's favorite Pokémon".

- **One-off date:** add to `dated`, e.g.
  `{ date: "2026-11-02", name: "J's favorite Pokémon", pokemon: ["eevee", "umbreon", ...] }`
- **Every week:** add to `weekly` with `weekday` (0 = Sunday … 6 = Saturday).
- **Random rotation:** add to `pool`. About `poolChance` (25%) of otherwise-normal
  days pick a pool theme; the same one won't repeat within 7 days.

Use ids from `data.js` (`"id":"..."`), or `match: (p) => ...` to pick Pokémon by
their data. Aim for 8+ Pokémon. Preview any day while running locally (see the main README) with `/pokopia-doku/?date=2026-11-02` (the live site ignores `?date`);
if a theme can't make a valid grid, the browser console shows a warning and that
day falls back to a normal grid. Unknown ids are also warned about in the console.

Editing `pool` (adding/removing/reordering) can change which pool theme past and
future days get, and changing any theme can change that day's grid.

## Tuning difficulty

All in `pokopia-doku/script.js`:

- `DIFFICULTIES` — per difficulty: the category-rating mix, answers allowed per
  square, guesses (`null` = unlimited), and hint rules.
- `WEEKDAY_DIFFICULTY` — which difficulty each weekday's Daily uses.
- `GROUP_RATINGS` / `RATING_OVERRIDES` — how hard each category is (1 easy – 3 hard).
  Categories with fewer than 12 Pokémon get +1 automatically.
